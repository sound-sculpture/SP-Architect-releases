**SP Architect — beta testers wanted**

Desktop live-set manager / librarian for **SP-303, SP-404 OG, SP-404SX/A, SP-404MK2 and SP-555**: set preparation, all pad parameters, audio conversion, card reading, export to card folder / ZIP / project. MK2 adds LOCAL-LIVE USB, patterns and screens.

Local only — no account, no telemetry. macOS (notarised) + Windows (portable ZIP), iPad in TestFlight (editor only, no USB).

Looking for testers on real cards/projects, and MK2 users for LIVE/patterns/screens. Back up your cards first. Download: https://github.com/sound-sculpture/SP-Architect-releases/releases/tag/v1.0.0-beta.2
