## Documentation references

Formats and the SP-404MK2 vendor protocol were established from public documentation and our own readings of the machines:

- **TuscanPL/SparkyMK2** (GPL-3.0) — protocol and file-format documentation. **No code is used.**
- **MatthewCallis/super-pads** (MIT) — SP-404SX/A `PAD_INFO.BIN` documentation.
- ConvertWithMoss, gsterlin/sp404mk2-tools, ciscoittech/sp404mk2-sample-agent — RFPD/RFWV observations.
- Community documentation for the SP-303 (`SMPINFO0`) and SP-404 OG (`WVCINFO0`).

No third-party source code is included in SP Architect.
